# Projeto AZUL
Site de leilão de itens raros da cultura Geek (action figures, cards e discos de vinil). Um site de leilão é uma plataforma onde pessoas ou empresas podem anunciar produtos ou serviços para que vários interessados disputem a compra por meio de lances. Em vez de existir um preço fixo, o valor aumenta conforme os participantes fazem ofertas, e quem der o maior lance dentro do tempo estabelecido vence o leilão. O nosso lucro vem de comissão das vendas (uma % do valor do item leiloado)

## Fluxo de uso
- O usuário cria uma conta.
- Publica um produto com fotos, descrição, lance inicial e duração do leilão (minimo de 3 dias).
- Outros usuários fazem lances (valor maior do que o anterior).
- O vencedor realiza o pagamento.
- Caso o lance seja coberto por um outro maior, o dinheiro volta para o usuário
- O sistema atualiza automaticamente o maior lance.
- Quando o tempo acaba, o maior lance vence.
- O vendedor envia o produto.
- Ambos podem se avaliar após a conclusão da compra.
