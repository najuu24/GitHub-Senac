# Projeto VERMELHO - CinePlanner
Nosso site tem como objetivo reunir a comunidade de cinéfilos em um só site. Ajudando a organizar, planejar e acompanhar a experiência do usuário com filmes.

Não é um site de compras de ingressos, nem de assistir filmes, é uma ferramenta de organização pessoal. 

## Como funciona?

O usuário pode:

- Compartilhar opiniões, receber feedback e curtidas relacionados a seu post
- Avaliar filmes
- Criar listas do que deseja assistir
- Organizar maratonas
- Controlar gastos com ingressos
- Pesquisar filmes através da API TMDb
- Personalizar seu perfil com base em seus interesses 
- Se conectar com outros cinéfilos

### Sistema de estatística (Retrospectiva)

Durante o uso do site o usuário poderá acompanhar:

- Filmes assistidos
- Tempo assistido
- Gêneros favoritos
- Gastos com cinema
- Metas concluídas

## Gamificação

Sistema de Pontos de Experiência baseado em sua atividade no site.
Conforme ele ganha EXP, ele sobe de nível.

### Recompensas

Ao subir de nível o usuário desbloqueia:

- Temas personalizados de perfil
- Ícones personalizados
- Molduras
- Insígnias 
- Títulos

## Planos de assinatura
